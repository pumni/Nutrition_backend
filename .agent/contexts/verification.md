Use when: maintaining ACL verification, selecting repository gates, validating context-layer changes, or consuming generated repository facts. The `agent-facts` gate verifies deterministic generated inventories and their provenance/freshness.
Do not infer: that an ignored integration test is a pass for a missing PostgreSQL environment, or that a future benchmark gate is universally runnable.

Modern verification uses Task Spec v2, progressive context routing, agent-owned plan/state, canonical gate IDs, trusted ControlRoot execution, modern scope envelopes, and generated fact freshness. Transitional v1 packets and their exact declared change checks are compatibility-only and must be explicitly named.

The foundation verifier runs formatting, Clippy, workspace tests, JSON parsing, sensitive-log scanning, and Docker Compose validation. PostgreSQL integration verification remains a separate gate and is not implied by ignored local tests.

Generated repository facts contain discoverable implementation data only: workspace/crate membership, source hashes, test inventory, routes, schemas, and path ownership. Human policy remains in `.agent/policies/`, invariants, authority documents, and the canonical verification map.

The trusted runner resolves commands from ControlRoot, validates external artifacts, writes evidence outside TargetRoot, and records bounded output metadata rather than raw command output. Scope and protected-decision checks remain fail-closed.
