# Behavioral evaluation tasks

The executable task inventory is evaluator-owned and supplied outside the subject repository. Each BEH-* task is a stable human-readable index into a real coding task; the control-plane JSON remains the single source of task semantics. The harness does not provide required context paths or protected-domain labels to the agent.

The harness copies only objective, acceptance criteria, and coarse scope into a disposable worktree, runs an adapter, and grades the resulting environment state, changed paths, hidden assertions, and persisted evidence.
